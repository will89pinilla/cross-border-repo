# Notas de T09 · Métricas, logs JSON y health

Decisiones y hallazgos acumulados para esta tarea.

- Revisión de seguridad de T07 (Claude): exponer solo `health` y `prometheus` (`management.endpoints.web.exposure.include=health,prometheus`). Nunca `env`, `configprops` ni `heapdump`: mostrarían las contraseñas de la base. `health` sin detalles (`show-details: never`) o con detalles solo de la base. Un test que verifique que `/actuator/env` y `/actuator/heapdump` responden 404.
- Los logs JSON no deben incluir el contenido de los eventos ni los bytes de los archivos; sí `load_id`, nombre de archivo, posición y códigos.
